# Swipe & Slide — Backend

API REST della dating app riservata ai consulenti.

Stack: Node.js + TypeScript, NestJS, PostgreSQL senza PostGIS (distanze calcolate con la formula
dell'emisenoverso tra i centroidi dei comuni ISTAT), Drizzle, contratto OpenAPI.

Progetto in fase di avvio: struttura iniziale non ancora creata.
